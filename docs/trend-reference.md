# Trend reference

**Last updated: (fill in when first populated — do not leave this blank)**

This is the only place "current" visual trends are allowed to live. No
skill in this repo should hardcode what "modern" looks like — anything
generated by an LLM (including this file's own first draft) reflects its
training cutoff, which is already stale by the time you read it. This file
is the team's job to keep current, on a quarterly cadence (see
`.claude/skills/trend-refresh/SKILL.md`).

Entries older than 2 quarters are marked stale below and should be
revalidated against 3-5 current live sites before reuse, not trusted as-is.

## How to fill this in (per quarter)

1. Pick 5-8 live sites currently doing well in your niches (Awwwards
   site-of-the-day in the relevant category, or direct competitor sites
   that are visibly newer/better than your last build).
2. For each, note: layout pattern, hero treatment, motion/interaction,
   color/type approach, what specifically makes it read as "current" vs.
   what's just competent.
3. Write the pattern, not the page — "oversized serif headline + single
   muted accent color + scroll-triggered reveal" is reusable, "looks like
   site X" is not.

## Standing rule regardless of quarter

Novel-tech (WebGL, heavy 3D, generative visuals) is not the default trend
signal — check `build-qa/SKILL.md`. A site can look dated for being
under-designed OR lose conversion for being over-built on a slow mobile
connection. Both are failures.
